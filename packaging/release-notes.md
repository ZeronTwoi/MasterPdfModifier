Download the file for your computer, start it, use it. No command line is involved anywhere.

**Windows** – `MasterPdfModifier-Setup.exe` installs the app: it asks where to, whether you want a shortcut on the desktop and whether to offer the app under "Open with" for PDF files, and needs no administrator. `MasterPdfModifier.exe` is the whole app in one file, for those who would rather not install anything: double-click it. Windows may say that it does not know either of them, because they are new and not signed: choose *More info*, then *Run anyway*.

**Linux** – `MasterPdfModifier.deb` for Debian, Ubuntu, Mint and their relatives: open it and let the software centre install it; the app is in the application menu afterwards. `MasterPdfModifier-Linux.tar.gz` for the others: unpack it and start `MasterPdfModifier`, which offers to put itself into the application menu.

What text recognition needs (language data, and on a fresh Windows the Microsoft Visual C++ runtime) is fetched by the app itself the first time it is used, after asking. Whether the app should tell you about new versions it asks once, at its first start; with a no it never connects for that.
