Download the file for your computer, start it, use it. Nothing else has to be installed, and no command line is involved.

**Windows** – `MasterPdfModifier.exe`. Double-click it. Windows may say that it does not know the app, because it is new and not signed: choose *More info*, then *Run anyway*.

**Linux** – `MasterPdfModifier.deb` for Debian, Ubuntu, Mint and their relatives: open it and let the software centre install it; the app is in the application menu afterwards. `MasterPdfModifier-Linux.tar.gz` for the others: unpack it and start `MasterPdfModifier`, which offers to put itself into the application menu.

What text recognition needs (language data, and on a fresh Windows the Microsoft Visual C++ runtime) is fetched by the app itself the first time it is used, after asking.
